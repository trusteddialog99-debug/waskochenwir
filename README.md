# Unser Wochenkochplan

## Start
```bash
pip install -r requirements.txt
streamlit run app.py
```

Die App enthält 183 herzhafte bzw. planungsrelevante Rezepte. Kuchen, Torten, Muffins, Kekse und vergleichbares Gebäck wurden aus der Ausgangsliste entfernt. Herzhafte Gerichte mit ähnlich klingenden Namen wie Flammkuchen, Pfannkuchen und Tortellini bleiben erhalten.

Falls eine frühere App-Version bereits gestartet wurde, bitte deren Ordner `data` löschen, damit die bereinigte Excel-Liste neu importiert wird.
